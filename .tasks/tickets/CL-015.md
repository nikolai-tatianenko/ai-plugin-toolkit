# CL-015: Cache services and optional embeddings

Status: implemented
Milestone: v0.3
Dependencies: CL-005, CL-013

## Scope

Add content/version keyed transforms and embeddings plus scope/permission/revision aware retrieval caching.

## Acceptance criteria

- Memory and permission changes invalidate cache entries; no cross-project hits; full cost includes cache maintenance.
- Record verification commands/results and relevant source or build revision.
- Document unsupported cases and remaining work; do not mark verified from mocks alone.
