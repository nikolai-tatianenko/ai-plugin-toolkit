Status: implemented

## Scope

## Acceptance criteria

- Importing identical synthetic input twice creates no duplicate sources; malformed input leaves no partial records.
- Record verification commands/results and relevant source or build revision.
- Document unsupported cases and remaining work; do not mark verified from mocks alone.

## Limitations and remaining work

- Supported inputs: `.json` (conversation schema in `packages/core/src/ingest.ts`), `.md`, `.markdown`, `.txt`, `.log`. Other formats are rejected.
- `--dry-run` validates and computes IDs but does not check which sources already exist.
- Unreferenced payload files after a failed batch are not yet collected (CL-013).
- Durable background-job table not yet added; belongs with CL-004 extraction.
- `node:sqlite` is experimental upstream (ADR 0003).
- GitHub Actions did not start on 2026-10-31: the account's billing/spending limit blocked the job. CI results are therefore not yet recorded; local and clean-clone runs only.
