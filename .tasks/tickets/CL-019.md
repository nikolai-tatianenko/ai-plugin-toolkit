# CL-019: Two-way sync and recovery hardening

Status: implemented
Milestone: v0.4
Dependencies: CL-013, CL-014

## Scope

Add remote change reconciliation, concurrent edit handling, migration rollback/recovery, and crash retries.

## Acceptance criteria

- Conflicting edits are preserved for resolution; interrupted sync resumes; task status ownership stays explicit.
- Record verification commands/results and relevant source or build revision.
- Document unsupported cases and remaining work; do not mark verified from mocks alone.
