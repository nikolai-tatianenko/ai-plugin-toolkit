# CL-003: Provider adapter and policy routing

Status: implemented
Milestone: v0.1
Dependencies: CL-001

## Scope

Implement one real provider with capability checks, budgets, cancellation, redacted traces, and allowed fallbacks.

## Acceptance criteria

- A timeout is bounded; a restricted project cannot fall back to a disallowed provider; missing credentials produce a clear error.
- Record verification commands/results and relevant source or build revision.
- Document unsupported cases and remaining work; do not mark verified from mocks alone.

## Limitations and remaining work

- The live provider path has not been run against the real API.
- Only one real provider. No local inference, so restricted projects can only use the `fixture` adapter today.
- Server-side model fallbacks are deliberately off; policy fallbacks are used instead (ADR 0004).
- The price table is static and dated; unlisted models report unknown cost.
