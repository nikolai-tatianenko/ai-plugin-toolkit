# CL-008: Evidence-backed acceptance report

Status: implemented
Milestone: v0.1
Dependencies: CL-007

## Scope

Implement separate applicability, verification, disposition, evidence revision/environment, and severity.

## Acceptance criteria

- A closed task or mock alone cannot satisfy real-device criteria; missing evidence remains unverified; stale revisions invalidate passes.
- Record verification commands/results and relevant source or build revision.
- Document unsupported cases and remaining work; do not mark verified from mocks alone.
