# CL-006: Versioned artifact generation

Status: implemented
Milestone: v0.1
Dependencies: CL-004, CL-005

## Scope

Generate facts, vision, plan, status, and decision records with provenance; preserve manual edits.

## Acceptance criteria

- Artifacts cite sources; repeat generation is stable when inputs are unchanged; manual-edit conflicts are surfaced.
- Record verification commands/results and relevant source or build revision.
- Document unsupported cases and remaining work; do not mark verified from mocks alone.
